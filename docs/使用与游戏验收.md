# 使用与游戏验收

本次提供 0.2.2 自动测试版本，尚未声明游戏内验收通过。请使用独立测试存档。开发过程中没有启动或操作你的游戏窗口，也没有修改现有 Mod 或玩家存档。调试入口和详细日志见《调试台与日志.md》。

## 文件与安装

1. `dist/player.portraitruntime` 是无美术核心库，`dist/player.launchgiftportraits` 是依赖核心的人物美化内容版，两个文件夹分开放置。游戏本地 Mods 路径是 `D:\SteamLibrary\steamapps\common\Probably Stolen\Mods`。
2. 你准备测试时，将该文件夹复制到 Mods 下；如目标已有同名文件夹，先把旧文件夹完整备份到 Mods 目录外。
3. 先把旧独立 `player.launchgiftportraits` 备份到 Mods 目录外，再复制新内容版。启用核心与新内容版，也可只启用核心。修改或加入文件后游戏可能要求重新信任。
4. 声明的能力为 files 与 reflection-external。不要在 Mod 目录里放 `*.dll.old` 等备份可执行文件。
5. 新建测试存档。人物美化主包默认启用，demo 与图标示范默认关闭；启用示范需修改美化 Mod 下对应 packs 子目录的 pack.json，再重启。

## 快捷键

- F10：显示设置；保存到运行时目录 `ui.json`。
- F3：调试台，可切换 F4；提供当天全部人物及剧情配图巡检。
- F11：向日志目录导出带会话 ID 的 diagnostics JSON。

## 第一轮：旧问题

核对伦警官、治安人员、商人、枪匠等共享精灵场景。治安人员与未配置 NPC 应保持原版；具名角色按各自身份显示。测试交易完成、离场动画与下一位客人，记录是否跳变。另检查清晨特殊来访与正常店内来访。

找出跨角色同文本“多谢，又来了。”与“多谢，是我。”，检查其剧情图归属。普通对话和 RichTextBuilder 路径均已接入台词来源记录，但实际触达与覆盖率尚需游戏日志确认。

## 第二轮：新增内容和真实存档

1. 启用 demo 包，从测试存档第 2 天开始按原生流程叫下一位，观察示范信使。
2. 选择“接收信号片”，确认获得 `demo.signal`，并能移动、拖拽、存入不同库存。
3. 手动保存、退出，再读同一测试存档。确认物品和选择仍在。
4. 第 3 天开始，回访信使应出现，发放 20 信用点并记录完成状态。已发放奖励不应重复。
5. 第 4 天开始，示范交易员出售与收购信号片。通过原生交易界面完成购买和出售，再保存读档检查。
6. 另开测试存档选择拒绝；接受分支的回访应不触发。
7. 在对话中途保存并重载，应恢复进行中的人物与节点；测试库存空间不足时奖励保持待执行，腾出空间后重试不重复已发部分。

示范立绘复用了核心包已有美术，只为验证内容流程；不是新增人物的最终专属美术。

## 第三轮：图标、优先级和缺包

将 `packs/icon-examples/pack.json` 的 enabled 改为 true，重启并重新信任后，五个指定实验室量具图标应有绿色测试边框。测试其占格、拖拽、取放；其它物品保持原版。

社区包按 priority 覆盖；同优先级按包 ID 确定性排序，冲突写日志。坏包应被隔离并指出原因。缺失包的剧情状态应保留；新增物品缺包的占位恢复、补回包后的恢复情况应单独记录，不要用正式存档冒险验收。

## 第四轮：显示与持续运行

F10 测试气泡、姓名框、立绘偏移和缩放，高清开关切换。窗口、中文字体、鼠标事件与不同分辨率尚未做实际游戏视觉验证。

连续游玩 30 分钟，记录进程内存和卡顿变化，F11 输出缓存字节与条目数。缓存会保留正在使用的贴图，不能仅用缓存预算推断总进程内存达标。

## 返回证据

优先提供：复现步骤、客人或物品名称、剧情句子、F11 导出的 diagnostics JSON、本轮详细 JSONL、巡检报告及游戏 Player.log 中 `[PortraitRuntime]` 附近的信息。无需上传整个存档或整个游戏文件夹。

常见日志目录：`C:\Users\Administrator\AppData\LocalLow\Questing Goose Studio\Probably Stolen\Player.log`。

## 工作台

双击 `workbench/index.html`。可查询全部客人注册项、普通物品及剧情/电话台词。新建立绘角色后选 PNG，在剧情中编辑节点与分支，再添加来店人物并关联角色和剧情。动作与条件目前用 JSON 编辑，字段见数据格式说明。

导入时选择单个内容包文件夹；导出会把 pack.json 和被引用的图片一起写入 ZIP。元数据与图片存于当前浏览器本地，换浏览器或清理网站数据前请先导出。

F10 游戏内窗口、工作台、命令行校验器是三个独立入口。工作台自动测试通过不表示游戏内窗口已通过。
